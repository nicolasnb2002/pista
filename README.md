# Pista

Diez días de Python y bases de datos para llegar a [AI Engineering de ICARO](https://icaro.org.ar/producto/ai-engineering/) leyendo código sin trabarse. Una hora por día.

El curso arranca en modelos, prompts, RAG, agentes y APIs. Pista es lo de antes: tipos, control de flujo, listas y diccionarios, funciones, errores, JSON, SQL y el puente entre Python y una tabla.

Python corre en el navegador. SQL corre en SQLite, también en el navegador. No hay cuentas. El avance queda guardado en el navegador de quien estudia.

## Cómo abrirla

```bash
npm install
npm run dev
```

Después abrí la dirección que indique la consola.

## Qué cubre

1. Valores, tipos y f-strings
2. Decisiones y bucles
3. Listas y diccionarios
4. Funciones
5. Errores y JSON
6. Consultar una tabla
7. Agrupar y unir
8. Guardar y modelar
9. Python con datos, sin inyección SQL
10. Armar el contexto que iría a un modelo
